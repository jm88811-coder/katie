# 사업가 성장 여정 — 예비 창업가를 위한 6단계 실행 가이드

> 창업 초기에 자주 막히는 지점을 "출발점 → 문제 발견 → 작게 팔기 → 운영 구조 → 돈·규정 → 성장·회고"의 6단계로 나눈 파운더스토리 자체 코칭 프레임입니다.
> 일반적으로 알려진 경영·행동경제학 개념(린 스타트업의 최소 기능 제품, 단위경제성, 손실 회피 등)을 활용해 앱에서 바로 실행할 수 있는 과제 중심으로 직접 구성했습니다. 특정 도서의 문구·장 구성·고유 용어를 사용하지 않습니다.

---

## 설계 원칙

1. **사람 → 시장 → 판매 → 운영 → 재무 → 성장** 순서로, 사업이 실제로 진행되는 흐름을 따른다.
2. 마음 습관(체면, 손실 집착, 완벽 기대, 책임 회피)은 별도 단계로 두지 않고 **각 단계의 "멈춤 신호"** 로 점검한다.
3. 모든 단계는 **측정 가능한 과제 3개 + 코치 질문 1개**로 끝난다.

---

## 1단계. 출발점 정리

내가 가진 것(강점·경험·시간·자금·사람)과 나를 붙잡는 것(직장 습관, 체면, 이미 쓴 시간·돈)을 한 장에 적는다.
**멈춤 신호**: 완벽해지면 시작하겠다며 준비만 길어짐.

## 2단계. 문제와 고객 찾기

팔 물건이 아니라 해결할 문제에서 출발한다. 불편 20개를 모으고, 후보를 4가지 기준(각 1~5점)으로 채점한다.

| 기준 | 질문 |
|---|---|
| 다시 산다 | 고객이 반복해서 구매하는가? |
| 내가 없어도 굴러간다 | 자동화·위임 여지가 있는가? |
| 따라 하기 어렵다 | 수요는 확인됐고 진입 장벽이 있는가? |
| 키울 여지가 있다 | 지역·인력 한계 없이 확장 가능한가? |

**멈춤 신호**: 남들이 좋다는 시장에 무리하게 합류함.

## 3단계. 작게 팔아보기

2주 안에 최소 기능 제품을 만들어 소규모로 판매한다. 설문이 아니라 **실제 결제**가 증거다. 구매·거절 이유를 판매 일지에 기록한다.
**멈춤 신호**: 공개하지 않고 계속 고치기만 함.

## 4단계. 운영 구조 세우기

일일·주간 리듬을 정하고, 반복 업무를 매뉴얼로 만들고, 실패 비용이 작은 일부터 위임·자동화한다.
**멈춤 신호**: 모든 일을 혼자 해야 안심됨.

## 5단계. 돈과 규정 지키기

이익보다 현금, 매출보다 단위경제성을 본다. 매출 40% 이상을 한 채널·거래처에 두지 않는다. 사업자등록·세금 일정·계약 기본 조항을 달력과 체크리스트로 관리한다.
**멈춤 신호**: 장부상 이익만 보고 현금 부족을 놓침.

## 6단계. 키우고 되돌아보기

성과를 내 실력 / 운영 구조 / 시장 타이밍으로 나누어 평가하고, 채널·상품 확장은 작은 실험부터 한다. 분기마다 회고를 고정한다.
**멈춤 신호**: 잘된 이유를 확인하지 않고 규모만 키움.

- [ ] 불편 20개 수집, 후보 3개 채점
- [ ] MVP 판매 테스트(실제 결제)
- [ ] 일일·주간 점검표, 매뉴얼 1~2개
- [ ] 현금흐름표와 의존도 계산, 세금·계약 점검
- [ ] 성과 원인 회고와 분기 회고 일정
