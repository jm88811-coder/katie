# 파운더스토리 (FounderStory)

> 당신의 이야기가 사업이 됩니다.

이름, 생년월일(시), MBTI/성향, 실패 경험담, 성공 경험담, 지향점·목적·목표를 입력받아
&mdash; 마치 사주를 보듯 &mdash; 나만의 사업가 원형을 진단하고, 자체 개발한 7단계 성장 프레임
(`docs/사업가-성장-여정.md`)을 챕터로 풀어 Step 1부터 사업가로 성장하도록
이끄는 AI 창업 코칭 앱입니다.

## 주요 기능

- **온보딩 프로필**: 이름·생년월일시·MBTI·실패/성공담·지향점/목적/목표 입력 → 사업가 원형 진단
- **7단계 여정** (`/journey`): 마음의 브레이크 점검 → 사업가의 시선 갖기 → 본능의 함정 피하기 → 일상 루틴 설계 →
  사업가의 공부 지도 → 아이템 고르기 → 성장기 리스크 관리, 챕터별 핵심 포인트/과제/코치 질문/진행률
- **영감 노트** (`/inspiration`): 국내외 이슈·불편·불만 큐레이션 + 나만의 아이디어 메모
- **고민상담** (`/consult`): 막히는 순간 키워드 기반으로 관련 챕터와 실행 조언 제공
- **세금·법률 체크리스트** (`/tax-legal`): 예비창업자 → 등록 직후 → 운영 중 → 확장기 단계별 안내
- **스터디 카테고리** (`/study`): 마인드셋부터 데이터/AI 활용까지 8개 분야 학습 로드맵
- **AI 시대 신직업** (`/ai-jobs`): 사업 아이템/커리어 전환 힌트가 되는 신직업군 소개
- **소개 & 벤치마킹** (`/about`): 유사 서비스(Rocky.ai, VeltoAI, Mindsera 등) 대비 차별화 포인트

## 현재 아키텍처 (MVP)

- Next.js 16 (App Router) + TypeScript + Tailwind CSS v4
- 별도 백엔드 없이 브라우저 `localStorage`에 프로필/진행률/노트를 저장하는 1인 사용자 MVP
- `src/lib/engine.ts`의 규칙 기반 개인화 엔진이 MBTI + 키워드 분석으로 사업가 원형과
  추천 챕터, 고민상담 조언을 생성 (추후 LLM API 연동으로 고도화 가능한 확장 지점)

## 개발


## 사주 사이트 (`/saju`)

가입·결제 없이 무료로 이용하는 사주 서비스. 만세력(절기 천문 계산) 기반 4주·오행·십성·용신·대운, 오늘의 운세, 2027 신년운세, 궁합, 전문가 상담 신청, 재방문 스트릭 보상(심층 리포트 해제), 광고/제휴 슬롯. 모든 계산·저장은 브라우저에서만 이뤄집니다. 로직은 `src/lib/saju/`, UI는 `src/components/saju/`.

### 달도령 · 인생 전략서 (`/saju/path`)

사주 결과 뒤에 "그래서 무엇을 할까"를 제안하는 층. 사주 계산값(일간 강약·오행·십성·대운·충)에 따라 철학 렌즈(도가·유가·주역·불교), 인생 시즌 지도, 위기→기회 카드, 분기 로드맵을 규칙 기반으로 조합하고 모든 풀이에 근거를 표시합니다(`src/lib/saju/wisdom.ts`). 캐릭터 "달도령"은 임시 SVG(`Dodlyeong`, `src/components/saju/motion.tsx`)이며 Framer Motion(`motion`)으로 애니메이션합니다(`prefers-reduced-motion` 존중). LLM·서버·결제는 없는 린 구성이며, 이후 Rive 캐릭터·Claude 풀이 생성으로 확장 가능합니다.

`/saju/path`는 챕터형 스크롤 서사(서장·지난 이야기·지금의 계절·흔들림과 기회·앞으로 90일 좋은 날/조심할 날 TOP10·올해의 길·마무리)로 구성되며, 과거 회고(질문형, 근거 표기)와 날짜 단위 행동 지시를 포함합니다. `/saju` 전체는 다크+골드(기본)/한지(라이트) 테마 토글을 지원합니다.

### AI 풀이 “달도령의 편지” (구성 B 1단계)

`/saju/path` 7장에서 사용자가 동의하면 `POST /api/saju/narrate`가 서버에서 사주를 다시 계산해 만든 "사실(facts)"만을 근거로 Claude가 8개 섹션의 편지를 스트리밍으로 작성합니다(`src/lib/saju/facts.ts`, `narrate.ts`). 근거 표기·단정 금지·프롬프트 주입 방어를 시스템 프롬프트에 두었고, 같은 출처 검사·IP당 시간당 3회·일일 상한(기본 200)·입력 검증으로 남용을 막습니다(인스턴스별 best-effort — 트래픽이 늘면 공유 저장소로 교체). 결과는 월 단위로 브라우저에 저장됩니다.

설정: `.env.example` 참고. `ANTHROPIC_API_KEY`가 없으면 기능은 "준비 중"으로 표시됩니다. 기본 모델은 `claude-opus-5-5`, 비용 절감은 `SAJU_AI_MODEL=claude-sonnet-5-5`. 개발 중 키 없이 확인하려면 `SAJU_AI_MOCK=1 npm run dev`(프로덕션에서는 무시).
